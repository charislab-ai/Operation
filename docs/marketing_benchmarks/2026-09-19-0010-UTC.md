## 1. 카드뉴스 "overlay" 레이아웃 심화 — 구체 수치와 최신 텍스트 효과

### 기본 원칙(수치 기준)

- **텍스트 분량**: 슬라이드당 최대 10~15단어, 2~3줄 이내로 제한. 그 이상은 모바일 화면에서
  가독성이 급격히 떨어짐.
- **폰트**: 산세리프(Helvetica, Arial, Montserrat류) 위주, 본문 크기 24~30pt 이상(30pt 미만은
  모바일에서 읽기 어려움). 제목용 1종 + 본문용 1종, 최대 2종까지만 사용.
- **대비/가독성 처리**: 사진 위에 텍스트를 직접 얹을 때는 (a) 반투명 다크/라이트 오버레이를
  사진 전체에 깔거나, (b) 텍스트 뒤에 반투명 카드(semi-opaque card)를 배치. 텍스트 색은 순수
  블랙/화이트에 가깝게, 얇은 폰트 굵기는 피함.
- **여백**: 정사각형 포맷은 가장자리에서 최소 60px, 4:5 세로 포맷은 좌우 60px·상하 80px 이상
  텍스트를 띄워야 함(인스타그램 UI의 좋아요/저장 아이콘이 하단 150px, 핸들/캡션이 상단 120px를
  가리기 때문).
- **일관성**: 캐러셀 전체 슬라이드가 동일한 템플릿(폰트, 여백, 색 규칙)을 유지해야 브랜드
  정체성이 생김.

### 2026년 뜨는 오버레이 텍스트 효과

- **"Text Behind Image"(텍스트가 사물/인물 뒤로 지나가는 3D 오버레이)**: 텍스트가 사람이나
  사물 뒤로 파고드는 듯한 입체감을 주는 효과로, 패션·라이프스타일·여행 계정에서 특히 많이
  쓰임.
- **투명 텍스트(Transparent Text)**: 글자 안으로 사진이 비치는 편집숍(에디토리얼) 룩.
- **매거진형 오버레이**: 지오메트릭한 타이포 레이아웃으로 여행/뷰티/럭셔리 계정이 고급스러운
  피드 톤을 만들 때 사용.
- 텍스트 오버레이가 있는 게시물은 이미지만 있는 게시물보다 평균 50% 더 높은 참여율을 보인다는
  조사 결과가 있음(여행/푸드 카테고리 기준).

### 우리 시스템에 바로 적용할 아이디어

- SnapTale·SPING의 overlay 틀 게시물에는 사진 전체에 은은한 다크 그라데이션(하단 40%만 어둡게)을
  깔고, 텍스트는 하단 1/3 영역에 2줄 이내로 배치 — 현재 카드뉴스 생성 로직에 "하단 그라데이션 +
  하단 정렬 텍스트" 프리셋을 기본값으로 추가할 만함.
- 첫 슬라이드는 "text behind image" 대신 구현이 쉬운 대안으로, 사진 속 인물/사물 실루엣을 피해
  텍스트를 배치하는 "네거티브 스페이스 인식" 규칙을 프롬프트에 추가하면 가독성이 개선됨.
- 릴스용 영상 오버레이 캡션에는 "20분 완성 OOO", "OOO 없이 하루 만에" 같은 즉시 가치를 알리는
  1줄 후킹 문구를 첫 1초 안에 노출하는 규칙을 적용(아래 4번 릴스 후킹 절과 연결).

## 2. 키즈 앱 — Lingokids의 "부모 UGC + 전문가 라이브" 전략

- Lingokids는 게임·노래·팟캐스트·영상 등 여러 포맷의 교육 콘텐츠를 앱 안에 통합해 제공하는
  유아 학습 앱으로, 2025년 9월 시리즈 D 1.2억 달러를 유치할 정도로 빠르게 성장 중.
- **인스타그램**: 소아과 전문의·교육학 전문가를 초청한 "인스타그램 라이브"를 정기적으로 운영,
  "스크린 타임을 죄책감 없이 쓰는 법(quality screen use)" 같은 부모들의 실제 고민을 주제로
  Q&A 형식 콘텐츠를 만듦.
- **틱톡**: 브랜드 계정이 직접 만드는 콘텐츠 외에, 부모 크리에이터들이 실제 아이와 함께 앱을
  쓰는 모습을 찍은 리뷰/브이로그 영상이 다수 유통됨. 메시지 축은 "죄책감 없는 스크린 타임
  (guilt-free screen time)" — "아이가 놀면서 배운다"는 점을 강조.
- 브랜드는 부모들의 고민(스크린 타임 죄책감, 언제부터 학습 앱을 써야 하는지 등)을 먼저 수집하고,
  전문가의 답변을 콘텐츠화하는 방식으로 "정보성 + 신뢰"를 동시에 확보.

### 우리 시스템에 바로 적용할 아이디어

- 터치러쉬·SPING Kids 계정에 "부모/보호자가 직접 등장하는 후기형 콘텐츠"를 정기 포맷으로
  추가 — 특히 SPING Kids는 "우리 아이 위치를 보며 안심했던 순간"을 부모 화자 톤의 캡션으로
  풀어내면 Lingokids의 "죄책감 없는 스크린 타임" 메시징과 유사한 신뢰 확보 효과를 낼 수 있음.
- 월 1회 "전문가 Q&A" 형식(육아 전문가 인용 또는 일반적으로 알려진 육아 팁을 카드뉴스로 정리)을
  키즈 관련 앱(터치러쉬, SPING Kids)에 넣어 정보성 콘텐츠 비중을 늘리는 것을 고려할 만함.

## 3. 캐주얼/하이퍼캐주얼 게임 앱 마케팅 — 2026년 최신 동향

- **플랫폼 이동**: 2026년 들어 틱톡의 오가닉 도달이 불안정해지면서, 비주얼 중심의 캐주얼 게임
  마케팅에는 인스타그램 릴스가 더 유망한 채널로 부상 중. 메타(인스타그램/페이스북)가 게임 UA
  예산을 다시 흡수하는 흐름.
- **"이거 무슨 게임이야?" 리액션 UGC**: 중독성 있는 캐주얼 게임 플레이 클립을 짧게 잘라 올리면
  "이거 게임 이름이 뭐예요?" 류의 댓글이 대량으로 달리며 참여를 유도하는 패턴이 여전히 강력함.
- **새티스파잉(satisfying) 진행/수집 영상**: 레벨 클리어, 희귀 아이템 획득, 컬렉션 완성 같은
  "시각적으로 만족스러운" 순간을 짧게 보여주는 영상이 조회수·공유를 동시에 끌어올림 — 시각적
  쾌감(satisfying) + 열망(aspiration)의 조합.
- **게임 장르 하이브리드화**: 전략 게임에 캐주얼 퍼즐 미니게임을 넣는 등, 장르를 섞어 캐주얼
  게임 특유의 "가볍게 보이는 광고"를 다른 장르 게임에도 적용하는 흐름이 확산 중.

### 우리 시스템에 바로 적용할 아이디어

- 터치러쉬 콘텐츠에 "고득점 순간/콤보 성공 순간"만 3~5초로 잘라 보여주는 짧은 릴스 포맷을
  추가하고, 캡션에 "이거 무슨 게임인지 궁금하면 프로필 링크로" 같은 호기심 유도 CTA를 실험.
- "레벨업/신기록 달성" 같은 새티스파잉 순간을 강조하는 카드뉴스(overlay 틀 + 숫자 강조 타이포)를
  주기적으로 발행해 아케이드 게임 특유의 "성취감" 감정을 시각화.

## 4. 인스타그램 릴스 후킹 기법 — 3초 룰과 트렌드 오디오 전략

- **3초 룰**: 시청자의 45%가 첫 3초 안에 이탈하므로, 릴스 알고리즘은 첫 2~3초의 후킹을 매우
  중요하게 평가함. 오디오를 켜고 보는 비율이 80%를 넘기 때문에 오디오 품질/타이밍도 함께
  중요.
- **후킹 유형**: (a) 호기심형 — "대부분의 크리에이터가 첫 3초에 저지르는 실수는…" 같이 답을
  궁금하게 만드는 문구, (b) 첫 프레임 텍스트형 — "끝까지 보세요", "이게 다 바뀌었어요" 같은
  화면 텍스트로 시선을 붙잡는 방식.
- **오디오 전략**: 트렌드 오디오는 이미 익숙한 곡이라 즉각적인 후킹 효과가 있고, 도달·발견에
  유리함(알고리즘이 상승세인 오디오에 붙은 콘텐츠를 적극적으로 밀어줌). 사용량 5만 회 미만이면서
  빠르게 증가 중인 오디오가 진입 타이밍으로 좋음. 반대로 브랜드 정체성 구축, 특정 발매 콘텐츠
  홍보, UGC 캠페인 운영 목적이라면 오리지널 오디오가 더 적합.
- **길이/완주율**: 신규 도달을 극대화하려면 15~90초 사이 길이를 유지. 알고리즘은 완주율을
  매우 중요하게 반영하므로, 30초 영상이 85% 완주율을 보이면 3분짜리 20% 완주율 영상보다 도달이
  훨씬 높음.

### 우리 시스템에 바로 적용할 아이디어

- ChaMu·SnapTale·터치러쉬의 릴스형 콘텐츠 스크립트 생성 시, 첫 문장(첫 1~2초에 노출되는 화면
  텍스트)을 반드시 "호기심 유발형 질문" 또는 "결과 예고형 문구"로 고정하는 템플릿 규칙 추가.
- 릴스 콘텐츠 길이 가이드를 15~30초 내외로 우선 제안하고, 완주율을 높이기 위해 엔딩에 "반전/
  결과 공개" 컷을 배치하는 구조(호기심 → 전개 → 반전/결과)를 스크립트 템플릿에 반영.
- 트렌드 오디오 사용이 가능한 채널(릴스)에서는 "사용량 급상승 중인 오디오"를 우선 후보로 삼고,
  브랜드 고유 톤을 강조하고 싶은 공지성 콘텐츠(신규 기능 출시 등)에는 오리지널 오디오/자체
  BGM을 쓰는 이원화 규칙을 마케팅 콘텐츠 생성 로직에 반영할 만함.
