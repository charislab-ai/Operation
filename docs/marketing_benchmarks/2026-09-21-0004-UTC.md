## 1. 퍼즐/리플렉스 게임의 "결과 공유 스코어카드" 바이럴 메커니즘

### 조사 내용

**Wordle**의 핵심 바이럴 장치는 초록/노랑/회색 이모지 사각형으로 이루어진 "결과 그리드"다.
정답 단어나 구체적 풀이 과정은 전혀 드러내지 않으면서도, 몇 번 만에 맞췄는지·어떤 순서로
힌트를 얻었는지를 시각적으로 압축해서 보여준다. 이 그리드가 트위터/인스타그램 스토리/페이스북
타임라인에 매일 대량으로 올라오면서 "다들 하는데 나만 안 하나?"라는 FOMO를 만들어냈고, 이것이
Wordle을 특정 마케팅 예산 없이 전 세계적 화제로 만든 결정적 요인으로 꼽힌다.
([Nutcracker Agency](https://www.nutcrackeragency.com/blog/marketing/wordle-what-can-we-learn-from-the-web-game-s-viral-success/), [beastoftraal.com](https://beastoftraal.com/2022/01/04/wordles-viral-marketing-tactic-makes-brilliant-use-of-people-as-media/))

**NYT Connections**도 동일한 문법을 계승했다. 파랑/보라/노랑/초록 등 카테고리별 색상 이모지를
격자로 배열해 "몇 번 틀렸는지, 어떤 순서로 카테고리를 맞췄는지"를 스포일러 없이 공유하게 한다.
([Wikipedia](https://en.wikipedia.org/wiki/The_New_York_Times_Connections))

2026년 모바일 게임 업계 트렌드 리포트들도 "플레이어는 게임 자체가 아니라 '감정의 순간'을
공유하고 싶어 한다"는 점, 그리고 스트릭(연속 기록)·리더보드·업적 배지 같은 장치가 공유 버튼을
누르게 만드는 핵심 트리거라는 점을 공통적으로 지적한다. 2026년 현재 이런 공유 콘텐츠의 최종
소비처는 틱톡·유튜브 쇼츠·인스타그램 릴스로 이동했다.
([Melior Games](https://meliorgames.com/best-practices/what-makes-a-game-viral-in-2026/), [Udonis](https://www.blog.udonis.co/mobile-marketing/mobile-games/gaming-trends))

### 실행 가능한 패턴

- **스포일러 없는 결과 그리드 자동 생성**: 터치러쉬 플레이 종료 시 "반응속도 구간(예: 0.15~0.20초=초록,
  0.20~0.30초=노랑, 0.30초 이상=회색)"을 라운드별로 색칠한 5~10칸짜리 격자 이미지를 자동 생성해
  공유 버튼과 함께 노출. 정확한 초 단위 숫자보다 "색 블록 패턴"을 전면에 내세워야 Wordle처럼
  "무늬만 보고도 잘했는지 알 수 있는" 시각적 즉시성이 생긴다.
- **일일 챌린지 프레이밍**: "오늘의 터치러쉬 #147" 식으로 날짜/회차 번호를 매겨 매일 같은
  포맷으로 반복 공유되게 하면, 팔로워 피드에 누적 노출되며 스트릭 인증 문화가 생긴다.
- **캡션 자동 삽입 문구 예시**: "오늘의 반응속도 그리드 🟩🟩🟨⬜🟩 — 너는 몇 초?" 처럼 그리드
  이모지를 캡션에 텍스트로도 병기하면 이미지 저장 없이 텍스트만 복사-붙여넣기 공유도 가능해져
  확산 마찰이 줄어든다(Wordle이 실제로 이 방식을 씀).
- SNS 카드뉴스/릴스 소재로도 활용: "이 격자, 무슨 게임 결과일까요?" 식의 호기심 유발형 티저
  포스트를 만들고 마지막 슬라이드에서 터치러쉬 다운로드 CTA 연결.

## 2. AI 음악 생성 앱의 "텍스트→노래" 바이럴 트렌드 (Suno #texttosong)

### 조사 내용

2026년 상반기 틱톡에서 확산된 "text to song" 트렌드는 사용자가 실제 문자메시지·DM 대화 내용을
Suno 같은 AI 음악 생성 툴에 그대로 붙여넣으면, 가사·보컬·반주가 모두 포함된 완성곡이 1분 이내로
만들어지는 것을 콘텐츠화한 것이다. 이렇게 만든 MP3를 CapCut 등으로 가져가 문자 말풍선이 화면에
뜨는 타이밍을 가사 타이밍에 맞춰 편집하는 것이 전형적인 제작 방식이다.
([Jack Righteous](https://jackrighteous.com/en-us/blogs/ai-music-distribution-guide/tiktok-strategy-for-suno-creators), [Musically](https://musically.com/2026/06/01/suno-is-riding-the-wave-of-tiktoks-new-text-to-song-trend/))

이 트렌드로 Suno 앱 다운로드가 한 주 만에 4배 증가해 일시적으로 미국·영국 앱스토어 음악
카테고리 1위를 기록했으며, 한 크리에이터는 자녀의 문자메시지를 가사로 만든 영상 하나로
조회수 980만 회, 팔로워 20만 명 증가, 한 달 광고 수익 약 4,000달러를 기록한 사례가 보고됐다.
([Shopifreaks](https://www.shopifreaks.com/suno-app-downloads-quadruple-as-tiktoks-text-to-song-trend-turns-text-histories-into-ai-generated-songs/))

Suno의 채널 전략 자체도 참고할 만하다: 트랙에서 루프가 잘 되거나 감정을 자극하는 10~15초
구간만 잘라 쓰고, 같은 사운드로 비주얼/캡션/포맷만 바꾼 2~3개 변주 영상을 만들며, **틱톡에
먼저 올리고 반응이 검증된 것만 인스타그램 릴스·유튜브 쇼츠로 재가공**하는 순서를 따른다.
([Jack Righteous](https://jackrighteous.com/en-us/blogs/ai-music-distribution-guide/tiktok-strategy-for-suno-creators))

### 실행 가능한 패턴

- **ChaMu 앱 자체의 "텍스트→벨소리/음악" 기능 홍보 포맷**: 실제 웃긴/공감되는 문자 대화(가상
  각색본)를 화면에 말풍선으로 띄우고, 그 내용이 노래 가사처럼 흘러가는 릴스를 제작 — 마지막
  컷에서 "이 노래, ChaMu에서 벨소리로 바로 저장했어요" CTA로 연결.
  실제 문자 대화가 아니라 "리뷰 코멘트를 노래로 재구성"하는 식으로 저작권/개인정보 이슈 없이
  변형 적용 가능.
- **선(先) 틱톡 검증 → 후(後) 릴스 이식 원칙**: 새로운 밈/포맷을 릴스에 바로 대량 투입하지
  말고, 반응 좋은 포맷만 릴스용으로 다시 편집해 올리는 순서를 콘텐츠 캘린더에 반영.
- **같은 사운드로 2~3개 변주 만들기**: 한 번 만든 배경음/후킹 문구를 비주얼만 바꿔 여러 편
  제작해 알고리즘 노출 기회를 늘리는 방식은 ChaMu·터치러쉬 등 짧은 후킹 포맷이 필요한 앱
  전반에 적용 가능.
- **해시태그**: `#texttosong` 류의 트렌드 해시태그처럼, 트렌드 자체를 태그명으로 굳혀 확산시키는
  방식은 자체 챌린지 해시태그(예: 터치러쉬의 결과 그리드 챌린지)를 만들 때도 참고할 수 있음.

## 3. 카드뉴스 "VS·Before/After 비교형" 레이아웃 신규 후보

### 조사 내용

현재 시스템의 카드뉴스 4틀은 `banded`(사진+하단 브랜드컬러 밴드), `overlay`(풀블리드 사진+
그라데이션 텍스트 오버레이), `bold_type`(작은 사진+초대형 타이포), `split`(좌측 컬러블록+
텍스트/우측 사진)로 정의되어 있다(`backend/app/graphs/schemas.py`). 이번 조사에서 확인한
비교형 레이아웃은 이 중 `split`과 화면을 나눈다는 점은 비슷하지만, **"두 대상을 명시적으로
대결·대조시키는 것 자체가 슬라이드의 핵심 메시지"**라는 점에서 구조적으로 다르다.

Canva·Visme·Venngage 등 인포그래픽 템플릿 플랫폼에서 공통적으로 확인되는 비교형 레이아웃의
특징:
- **Before/After 좌우(또는 상하) 병치**: 동일한 프레이밍·구도로 촬영된 두 이미지를 나란히
  배치하고 각각 "Before"/"After" 라벨을 큼직하게 붙이는 방식이 표준. 다이어트·홈 인테리어·
  제품 업그레이드 계열 콘텐츠에서 가장 널리 쓰인다.
  ([PixGrid](https://pixgrid.io/before-and-after-carousel-maker))
- **VS 대결형**: 좌우를 정확히 2분할하되, 중앙에 "VS" 텍스트나 화살표·체크마크(✅/❌) 아이콘을
  배치해 "이건 되고 저건 안 된다"는 대비를 시각적으로 강조. 금융 콘텐츠에서는 상승/하락을
  나타내는 화살표 등 방향성 그래픽을 적극 활용한다.
  ([Venngage](https://venngage.com/blog/6-comparison-infographic-templates/))
- **최적 스펙**: 인스타그램 피드 기준 1080×1350px(4:5 세로형)이 표준이며, 슬라이드 하나에는
  통계 하나·메시지 하나만 담아 여백을 확보하는 것이 권장된다(정보 과밀 방지).
  ([EmbedSocial](https://embedsocial.com/blog/instagram-carousel-posts/), [DesignRush](https://www.designrush.com/best-designs/infographics/trends/instagram-infographics))

### 실행 가능한 패턴 (신규 레이아웃 후보로 기록)

- **레이아웃 명칭(가칭) `contrast`**: 슬라이드를 정확히 좌/우 또는 상/하 50:50으로 나누고,
  각 절반에 이미지 또는 색상 배경을 채운 뒤, 경계선 위에 원형 배지로 "VS" 또는 "BEFORE/AFTER"
  텍스트를 겹쳐 배치. `split`과 달리 양쪽 모두 시각적 무게가 동등해야 하며, 한쪽만 텍스트이고
  한쪽만 사진인 `split`과 구분되는 지점.
- **SnapTale 적용 예**: "정리 안 한 사진첩(왼쪽, 흐릿하고 뒤섞인 썸네일 목업)" vs "SnapTale로
  정리한 포토북(오른쪽, 깔끔한 커버 목업)" 대비 슬라이드.
- **터치러쉬 적용 예**: "평균 반응속도 0.35초(일반인)" vs "터치러쉬 상위 랭커 0.15초" 같은
  숫자 대비를 중앙에 화살표/차이값과 함께 배치.
- **ChaMu 적용 예**: "일반 벨소리 앱: 광고 5초 시청 후 다운로드" vs "ChaMu: 3초 만에 완성"
  같은 프로세스 비교.
- 위 레이아웃은 기존 4틀 스키마에 즉시 반영하려면 `schemas.py`의 `Literal` 값 추가와 렌더러
  구현이 필요한 코드 변경 사항이므로, 이번 조사에서는 실제 서비스 코드는 건드리지 않고
  "적용 근거 있는 후보"로만 기록함(기존 스크랩북/파노라믹/믹스드미디어 후보와 동일한 처리).
