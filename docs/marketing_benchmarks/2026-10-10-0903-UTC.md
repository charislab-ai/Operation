## 1. 카드뉴스 시각적 레이아웃/틀

### 1-1. 에디토리얼 레이아웃 3분류 재확인 (신규 spec 없음)

업계 가이드가 캐러셀 레이아웃을 크게 3가지로 분류하는 것을 재확인했습니다
([SearchEngineJournal 계열 best-practices 글](https://legacy.visitoverlandpark.com/?p=91983)):

- **그리드형**: 여러 이미지/텍스트 블록을 격자로 분할
- **히어로 이미지형**: 한 장의 강한 이미지가 화면을 지배(예시로 언급된 구찌류 패션 브랜드 방식)
- **시퀀셜 스토리텔링형**: 장마다 스토리가 순서대로 전개

→ 이 3분류는 기존에 등록된 **매거진 카드형**(그리드/히어로), **오버레이 기본형**,
**스크랩북형** 조합으로 이미 표현 가능합니다. 신규 spec은 제안하지 않습니다.

### 1-2. "스와이프 비교(Before/After Reveal)" 캐러셀 구성 — 신규 확인 (콘텐츠 패턴, spec 아님)

[Sked Social 2025/2026 가이드](https://skedsocial.com/blog/creative-ways-to-use-instagram-carousels-in-2025.md)에서
확인한 패턴입니다. 단일 이미지로 전/후를 나란히 보여주는 대신, **여러 슬라이드에 변화를 분산**시켜
"스와이프하며 다른 점 찾기(spot the difference)" 식으로 구성합니다.

- 1번 슬라이드: 원본 상태
- 중간 슬라이드들: 조금씩 바뀐 상태를 하나씩 보여줌
- 마지막 슬라이드: 전체 변화를 한번에 정리/공개

이건 **단일 카드의 시각 틀**이 아니라 **여러 장에 걸친 서사 구성 전략**이라 `layout-spec`
대상은 아니지만, 콘텐츠 기획에 바로 쓸 수 있습니다. 예: ChaMu "믹싱 전/후 음질 비교"를
한 장이 아니라 3~4장에 걸쳐 단계적으로 보여주기, SNAPTAIL "빈 포토북 → 완성된 포토북"을
페이지가 하나씩 채워지는 것처럼 슬라이드로 분산.

## 2. Touch Rush 직결 — 퍼즐/캐주얼 게임 광고의 "실패 시연 챌린지형 훅" + 플레이어블 설계 데이터

[Mega Digital 2026년 6월 글](https://megadigital.ai/en/blog/tiktok-ads-for-puzzle-games/)과
[Segwise 블로그(AppMagic 2025년 4월 데이터 인용)](https://segwise.ai/blog/idle-weapon-shop-playable-ads-strategy)에서
확인한 내용입니다.

- **3초 법칙**: 첫 3초 안에 궁금증/답답함/쾌감 중 하나를 압축해서 보여줘야 클릭률이 유지된다는
  원칙을 재확인(10-07-0905 "레이지베이트" 조사와 같은 맥락이지만, 이번엔 **광고 포맷 설계
  디테일**이 다름).
- **챌린지형 훅**: 플레이어가 레벨을 매칭하려다 "일부러 실패"하는 장면을 보여줘 "나는 저거
  이길 수 있는데" 하는 자기효능감/FOMO를 자극. 실제로 시청 시간·공유 수를 끌어올린다는 분석.
- **플레이어블 광고 설계**: 2025년 데이터 기준, 성과가 좋은 플레이어블 광고의 70% 이상이
  "끝까지 완료되지 않고 갑자기 끊기는" 구조였음. 티저보다 "~해봐"식 지시형 문구(challenge
  phrasing)가 더 잘 작동.
- **2026년 7월 크리에이티브 볼륨 데이터**([SocialPeta](https://socialpeta.com/en/blog/top-mobile-game-ad-creatives-and-advertising-trends-in-july-2026)):
  퍼즐/캐주얼 장르가 크리에이티브 생산량 1위, 세로형 720×1280 비율이 최다 노출 포맷.

**적용 아이디어**: Touch Rush 숏폼 광고를 만들 때 ①첫 3초에 "실패 직전" 장면을 배치하고
②자막을 "이거 할 수 있어?" 같은 도전형 문구로 ③영상을 일부러 애매하게 끝내 "직접 해보고
싶게" 유도. 세로 720×1280(또는 9:16) 비율을 기본값으로.

## 3. SNAPTAIL 직결 — Artifact Uprising UGC 전략 + Keepsake 광고 메시지

[Later.com 케이스 스터디](https://later.com/case-studies/artifact-uprising/)와
[광고 라이브러리 트래킹 페이지](https://adlibrary.com/brands/artifact-uprising-instagram-ads)에서
확인한 내용입니다. (주의: 원 사례 자체는 2016~2017년산으로 오래됐지만, 전략 구조는 현재도
포토북 업계에서 반복 사용되는 패턴이라 참고 가치가 있습니다.)

- **UGC 전량 재게시 + 전원 댓글 응답**: Artifact Uprising은 자체 제작 이미지보다 고객이
  태그한 UGC를 압도적으로 많이 리그램하고, 태그된 모든 게시물에 "진심이 느껴지는" 댓글을
  남기는 것을 운영 원칙으로 삼음.
- **크로스채널 메시지 재사용**: 페이스북에서 쓰던 이미지·카피를 거의 그대로 인스타그램에
  이식해도 성과가 나옴(광고 성과 +30% 보고) — 채널별로 새로 만들 필요 없이 "검증된 메시지"를
  재활용하는 효율 전략.
- **Keepsake(맞춤 액자 인쇄 DTC 브랜드)**: Meta 광고를 온라인 판매 핵심 채널로 운영 중이라는
  점만 확인(세부 소재는 유료 광고 라이브러리라 미확인).

**적용 아이디어**: SNAPTAIL도 완성된 포토북을 받은 유저의 태그/DM 인증샷을 모아 "리그램 +
직접 댓글" 루틴을 운영 규칙으로 고정하고, 페이스북에서 반응 좋았던 캡션/이미지를 인스타그램에
재활용하는 것을 기본 프로세스로 삼을 수 있음.

## 4. ChaMu 직결 — 인스타그램 가사 스티커(Musixmatch) + CapCut 자동 자막 대안

[LALAL.AI 가이드](https://www.lalal.ai/blog/how-to-add-your-song-lyrics-to-instagram-stories/),
[Amuse 가이드](https://www.amuse.io/content/how-to-add-your-song-lyrics-to-instagram-stories),
[label-worx 가이드](https://support.label-worx.com/hc/en-us/articles/360007384059-How-do-I-make-lyrics-available-on-Instagram)에서
확인했습니다.

- 인스타그램 스토리/릴스의 "음악" 스티커에서 **공식 가사가 보이려면** 곡이 Musixmatch에
  등록되고 아티스트 인증(Verified Artist Account)을 받아야 함. 승인까지 며칠 소요.
- 공식 등록이 안 된 곡(저작권·라이선스 문제로 벨소리 편집 앱이 흔히 겪는 상황)은 공식 가사
  스티커를 쓸 수 없음 → 대안으로 **CapCut류 외부 편집 앱의 자동 자막(오토캡션) 기능**으로
  자체 자막을 입히는 방법이 실무에서 쓰이고 있음.
- 가사 스티커는 폰트·애니메이션·색상을 고를 수 있어 바이럴 사운드 조각을 "가사 카드" 형태로
  보여주는 콘텐츠에 잘 맞음.

**적용 아이디어**: ChaMu가 벨소리/커버 편집 결과물을 홍보할 때, 저작권이 걸린 원곡은 공식
가사 스티커 대신 자체 자막(화면 안에 가사/효과음 텍스트를 직접 디자인)으로 "가사 카드"
비주얼을 만들어 레일스/스토리에 올리는 방식을 쓸 수 있음. 등록 가능한 자체 제작 음원(앱
내 커스텀 벨소리)이 있다면 Musixmatch 등록을 검토해 공식 가사 스티커 노출을 노려볼 수 있음.
