## 1. 카드뉴스 레이아웃 재점검 — "셰이프 컷아웃 효과"는 신규 틀 아님

### 검색으로 확인한 사실
- Picsart 블로그가 소개하는 **"Shape Cutout Effect"**: 단색(파스텔) 배경 위에 하트 등 도형
  모양으로 구멍을 뚫어 그 안으로 사진이 비치는 효과. 2개 레이어(하단 단색 + 상단에 도형이 뚫린
  사진)로 구성되며, 제작 과정은 지우개 툴 + 도형 + 반전(invert) 한 번뿐으로 매우 간단.
  크리에이터 @moonsol.design의 튜토리얼이 인스타그램·틱톡에서 좋아요 7.7천, 노출 58만 회를
  기록한 바이럴 포맷.
  ([Picsart Blog](https://picsart.com/blog/shape-cutout-effect-trend/))
- 관련해서 함께 확인된 흐름: 콜라주 그리드 + 은은한 드롭섀도 + 브랜드 폰트 오버레이 조합이
  2026년 카드뉴스에서 "레이어드/입체감" 있는 룩을 만드는 공통 기법으로 언급됨.
  ([DesignLumo](https://www.designlumo.com/resources/trends-for-social-media-post-makers))

### 판단: 신규 spec 미등록
컷아웃 효과의 핵심(단색 배경 + 도형 안에 사진이 보이는 룩)은 **이미 지원되는 enum 조합**으로
재현 가능합니다: `background: brand_gradient`(단색/그라디언트 배경) + `photo_style: circle`(원형
사진 창) + `photo_area: center`(중앙 배치) + `text_panel: plain` + `text_position: bottom`.
등록된 "후기 인증 카드형"도 이미 `photo_style: circle`을 쓰고 있어, 이번 발견은 "새 구성 요소가
필요한 틀"이 아니라 "기존 요소의 새로운 조합 아이디어"에 더 가깝습니다. 따라서 이번 회차는
새 layout-spec을 제안하지 않고, 대신 디자이너가 참고할 조합 팁만 아래에 남깁니다.

**바로 적용할 수 있는 아이디어**:
- `brand_gradient` 배경 + `photo_style: circle` + `photo_area: center` 조합을 "결과물 자랑"
  슬라이드(예: ChaMu 벨소리 완성 화면, Touch Rush 최고 기록)에 실험적으로 적용해 "창을 통해
  들여다보는" 느낌을 시도해볼 것을 제안.
- 콜라주 그리드 + 드롭섀도 조합은 기존 "매거진 카드형"·"스크랩북형"에 그림자 강도만 조정해도
  흉내 가능 — 별도 등록 불필요.

## 2. 인스타그램 캡션 후킹 공식 + 해시태그 5개 제한(2025년 12월~)

### 검색으로 확인한 사실
- **"125자 룰"**: 인스타그램은 캡션의 앞부분(대략 125자)만 보여주고 나머지는 "더 보기"로
  숨긴다. 실제 참여의 대부분이 이 125자 안에서 결정되며, 대부분의 사용자는 "더 보기"를 누르지
  않는다.
  ([boomp.net](https://boomp.net/blog/instagram-caption-best-practices-2026))
- **후크-가치-CTA(Hook-Value-CTA) 공식**: 첫 125자 안에 후크(왜 이 게시물이 중요한지) → 중반에
  가치 전달(맥락 한 문장 + 혜택 한 문장) → 마지막에 구체적 CTA. 후크는 "속이는" 문장이 아니라
  이 게시물이 "나를 위한 것"임을 알아보게 하는 문장이어야 한다는 점이 강조됨.
  ([Aibrify](https://aibrify.com/blog/how-to-write-instagram-captions-engagement-2026))
- **해시태그 5개 강제 상한(2025년 12월 시행)**: 인스타그램이 게시물·릴스에 해시태그를 **최대
  5개로 강제 제한**. 캡션과 첫 댓글에 나눠 달아도 합쳐서 5개가 상한이며, 초과 시 게시가
  차단되거나 초과분이 제거됨. 스팸성 "해시태그 도배" 계정 대응이 목적.
  ([SocialMediaToday](https://www.socialmediatoday.com/news/instagram-implements-new-limits-on-hashtag-use/808309/),
  [DigitalApplied](https://www.digitalapplied.com/blog/instagram-limits-hashtags-5-organic-reach-strategy-2026))
- **해시태그 5개 전략**: 니치 태그 1개 + 포맷 태그 1개 + 지역 태그 1개 + 주제 태그 1개 + 넓은
  태그 1개처럼 "역할을 나눠" 5개를 채우는 것이 권장됨. 10개 이상 남발했을 때보다 3~5개 정예
  태그를 쓸 때 참여율이 약 25% 높다는 수치도 확인.
  ([Later](https://later.com/blog/ultimate-guide-to-using-instagram-hashtags/))
- **해시태그 대신 커진 신호**: 해시태그 상한 이후 도달의 무게중심이 **캡션 키워드, 대체 텍스트
  (alt text), 오디오 어트리뷰션(사용 음원 표기), 화면 내 텍스트(OCR로 읽히는 카드 안 문구)**로
  옮겨갔다는 점이 여러 소스에서 공통 언급됨. 즉 카드뉴스 이미지 안에 박힌 텍스트 자체도
  검색·추천 신호로 읽힌다는 뜻.
  ([Later](https://later.com/blog/ultimate-guide-to-using-instagram-hashtags/))
- 위치 태그를 단 게시물이 그렇지 않은 게시물보다 참여율이 79% 높다는 수치도 확인됨.
  ([SocialKit](https://socialk.it/en/blog/instagram-hashtag-strategy))

### 우리 시스템에 바로 적용할 아이디어
- **캡션 생성 프롬프트에 "125자 후크" 규칙 강제**: content_strategist가 캡션을 쓸 때 첫 문장
  (약 125자 이내)에 후크가 끝나도록, "이 문장만 봐도 게시물이 누구를 위한 것인지 알 수 있게"
  라는 체크리스트를 프롬프트에 명시. 현재 캡션 구조가 후크-가치-CTA 3단으로 나뉘어 있는지
  점검 필요.
- **해시태그 자동 생성 로직을 5개 강제 상한 + 역할 분산 방식으로 재점검**: 태그를 "많이 달수록
  좋다"는 가정으로 생성하고 있다면, 니치/포맷/지역/주제/광의 태그 각 1개씩 5개만 뽑도록
  프롬프트·후처리 로직 수정이 필요할 수 있음(현재 로직 확인 필요 — 이번 조사는 정책 확인까지만
  담당).
- **대체 텍스트(alt text) 자동 생성 도입 검토**: 인스타그램 게시 API로 이미지 업로드 시 alt
  text 필드를 채우고 있는지 확인 — 해시태그 대체 신호로 중요해졌으므로, 카드 문구를 요약한
  alt text를 자동 생성해 함께 전송하는 것을 로드맵에 추가 제안.
- **카드 안 텍스트도 "검색어"로 취급**: 카드뉴스 헤드라인/본문 문구를 지을 때 앱 이름·핵심
  기능어(예: "포토북", "벨소리", "반응속도") 같은 실제 검색 키워드를 자연스럽게 포함시키는
  것을 카피 가이드라인에 추가(화면 내 텍스트가 OCR로 읽혀 도달에 반영되므로).
- **위치 태그 실험**: 페이스북/인스타그램 게시 시 "대한민국" 또는 관련 지역 위치 태그를 붙이는
  옵션을 테스트해볼 것을 제안.

## 3. ChaMu — "바이럴 사운드 → 벨소리 변환" 튜토리얼형 콘텐츠 포맷

### 검색으로 확인한 사실
- 벨소리 제작 앱들의 실제 바이럴 동력은 "AI가 만들어준 벨소리"가 아니라 **"이 틱톡/릴스
  사운드를 내 벨소리로 만드는 법"이라는 튜토리얼 콘텐츠** 자체인 것으로 확인됨. Zedge(5억+
  다운로드, 벨소리 앱 시장 리더)의 마케팅 문구도 "바이럴 밈부터 로파이 비트까지, 몇 초 안에
  벨소리로" 식으로 "빠른 변환" 자체를 세일즈 포인트로 내세움.
  ([mwm.ai](https://mwm.ai/apps/ringtone-maker-custom-tones/6742378271))
- 틱톡에서 "How to make any TikTok your ringtone" 류 튜토리얼이 트렌드 해시태그와 함께 꾸준히
  소비되고 있으며, "순간의 바이브를 그대로 포착"한다는 점이 소구 포인트로 언급됨.
  ([TikTok Discover](https://www.tiktok.com/discover/how-to-make-a-tiktok-video-your-ringtone))
- **폰크(Phonk)** 장르가 2026년 벨소리·알림음 트렌드의 주요 카테고리로 부상했으며, 빠른 컷·
  강렬한 전환이 특징인 릴스(짐 에딧, 카 릴스 등)와 결합해 소비되는 것이 확인됨.
  ([Spotify Playlist](https://open.spotify.com/playlist/4Wfk7WK7tulpnZd9Q1yflT))

### ChaMu에 바로 적용할 아이디어
- **"이 노래/사운드를 벨소리로 바꾸는 법" 튜토리얼 시리즈**: ChaMu 앱 화면을 활용해 "인기
  틱톡/릴스 음원 → ChaMu로 몇 초 만에 벨소리 완성" 과정을 짧은 릴스로 매주 시리즈화. 기존
  "기능 소개" 캐러셀보다 "따라 하고 싶은" 튜토리얼 포맷이 UGC 확산에 더 유리할 것으로 판단.
- **폰크 등 트렌드 장르 벨소리를 별도 카테고리로 강조**: 카드뉴스/릴스 소재에 "폰크 벨소리",
  "짐/운동 벨소리" 같은 장르·상황 태그를 붙여 특정 취향 커뮤니티(운동, 카 라이프 등)를 겨냥한
  콘텐츠를 실험.
- **"순간을 벨소리로" 카피 앵글**: Zedge식 "바이럴 밈부터 로파이 비트까지" 같은 폭넓은 무드
  스펙트럼 카피를 참고해, ChaMu 캡션에도 "이 순간의 분위기를 그대로 벨소리로" 식의 감성+속도
  결합 문구를 실험적으로 적용.
