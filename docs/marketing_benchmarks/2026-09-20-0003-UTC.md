## 1. 카드뉴스/캐러셀 "스크랩북·폴라로이드형" 레이아웃 + 콘텐츠 구조 5유형

### 1-1. 시각적 레이아웃: 스크랩북형(Scrapbook-style carousel)

- 확인 사례/자료: Ivory Mix의 "Seamless Scrapbook-Style Instagram Carousel" 제작 가이드, Feedbird의
  콜라주 템플릿 가이드, PicCollage 블로그의 인스타 콜라주 레이아웃 20종, Canva 폴라로이드 스토리
  템플릿(2만 개 이상 템플릿 보유 — 그만큼 수요가 크다는 방증).
- **구체적 시각 구조**:
  - 폴라로이드 프레임(흰 테두리 + 하단 여백)을 사진 위에 얹고, **사진이 슬라이드 경계를 살짝
    벗어나도록(bleed)** 배치해 "책상 위에 사진을 늘어놓은" 느낌을 냄 — 정확히 프레임 안에 딱 맞추는
    banded/overlay 틀과 대비되는 "일부러 삐뚤빼뚤한" 레이아웃.
  - 사진 여러 장 + 마스킹테이프·스티커·손글씨 폰트 텍스트를 겹쳐 "일기장/스크랩북" 감성 연출.
  - **일관성 유지 규칙**: 슬라이드마다 레이아웃이 달라 보여도 ①메인(히어로) 사진 하나를 정하고
    나머지는 보조로 배치, ②폰트·테두리 두께·스티커 색상 중 "반복 요소 하나"를 전 슬라이드에 통일 —
    안 그러면 "카드뉴스틀"이 아니라 "중구난방"이 됨.
  - Z세대 크리에이터 사이에서 "과도하게 정돈된" 느낌보다 **캐주얼하고 진짜(authentic) 같은** 톤으로
    소구할 때 특히 선호됨.
- **우리 시스템 적용 아이디어**:
  - SnapTale(포토북)이 가장 자연스러운 적용처: "이번 주 우리 아이 사진 모음", "여행 추억 모음" 류
    콘텐츠에서 기존 banded/overlay 대신 스크랩북형을 5번째 레이아웃 옵션으로 추가 검토할 가치가 있음.
    단, 로고/CTA가 들어가는 첫·마지막 슬라이드는 기존 정형 레이아웃 유지하고, **중간 슬라이드(사진
    나열용)에만** 스크랩북형을 섞는 하이브리드 구성을 권장(브랜드 정보 슬라이드까지 삐뚤빼뚤하면
    가독성이 떨어짐).
  - 폴라로이드 프레임 + 손글씨풍 캡션은 SPING(현장 사진 공유)에도 적용 가능 — "방금 이 순간" 같은
    현장감을 강조하는 데 스크랩북 프레임이 잘 맞음.

### 1-2. 캐러셀 콘텐츠 구조 5유형 (레이아웃이 아닌 "내용 구성" 패턴)

국내 마케팅 큐레이션(Threads @solution.kim, "터지는 캐러셀 콘텐츠 유형") 및 2026 캐러셀 가이드
(linkfarm.ai)에서 확인한, 저장·공유가 잘 되는 캐러셀 콘텐츠 구조:

1. **VS 스타일(전후 비교)**: 슬라이드를 Before/After로 나눠 변화를 시각적으로 보여줌 — "저장 편집
   전/후", "필터 전/후" 같은 변화가 눈에 보일 때 저장 유도가 강함.
2. **프리즈 프레임(영상→캐러셀 재가공)**: 이미 검증된 영상 콘텐츠의 핵심 장면을 캡처해 캐러셀로
   재구성 — 하나의 소재를 릴스와 캐러셀 두 포맷으로 재사용해 제작 효율을 높임.
3. **유명세 활용**: 이미 관심 있는 인물/사례를 요약해 첫 슬라이드 후킹에 사용.
4. **TOP5/모음집형**: "OO 앱 활용법 TOP5" 처럼 번호가 매겨진 리스트 — 완독률(끝까지 넘겨보게 만드는
   구조)이 높음.
5. **저장 유도형**: 슬라이드 자체가 "나중에 다시 볼 정보"로 설계되어(체크리스트, 단계별 가이드)
   저장 버튼을 직접 유도.
- **적용 아이디어**: 우리 시스템의 마지막 슬라이드 CTA 문구를 "저장하고 나중에 다시 보세요" 식으로
  1번(저장 유도형) 문법을 명시적으로 넣는 것과, ChaMu/터치러쉬의 "업데이트 전/후" 기능 비교나
  "이 앱으로 만든 벨소리 전/후"를 VS 스타일로 구성하는 안을 검토할 만함.

## 2. 브랜드 마스코트 인스타툰/밈 콘텐츠 실제 사례

### 2-1. Duolingo 부엉이 'Duo'

- 확인 사례: Fast Company("More famous than Mickey Mouse"), Enrich Labs 케이스 스터디, Influencers
  Time 시리즈 기사.
- **핵심 전략 구조**:
  - Duo를 "잘 관리된 브랜드 자산"이 아니라 **리믹스 가능한 밈 포맷**으로 설계 — 소셜팀에 크리에이티브
    자율성을 주고, 유저들이 자유롭게 2차 창작(팬아트, 패러디)을 만들도록 방치/장려함.
  - 톤은 "귀여운 마스코트"가 아니라 **뻔뻔하고 과장된(chaotic) 성격** — "숙제 안 하면 쫓아온다"는
    식의 협박 개그, 트렌드 오디오에 반응하는 콩트, 자기 자신을 소재로 한 밈("마스코트 다큐 놀리기")
    등 자기 풍자적 유머가 핵심.
  - **하나의 소재를 멀티포맷으로 재활용**: 부엉이가 유행 음원에 반응하는 콩트 하나를 틱톡·릴스·숏츠에
    거의 그대로 재배포(약간의 편집만 추가) — 제작 리소스 대비 도달을 극대화.
  - 성과 지표: 트렌드 오디오 반응 콩트 하나가 60만+ 인게이지먼트, 21.5% 참여율(업계 평균 상회) 기록.
- **우리 시스템 적용 아이디어**:
  - 각 앱 마스코트(있다면)에게 "정중하고 친절한 안내 캐릭터"보다 **살짝 뻔뻔하거나 과장된 성격**을
    부여해 밈화 가능성을 높이는 방향 고려 — 예: ChaMu 마스코트가 "벨소리 안 바꾸면 매일 같은 알림음
    듣는다"는 식의 과장된 잔소리 캐릭터, 터치러쉬 마스코트가 "네 반응속도가 이 정도라니" 식으로
    유저를 놀리는 개그 컷.
  - 인스타툰 에피소드 하나를 만들 때 릴스용 짧은 버전(핵심 컷만 3~4개 이어붙인 3~6초 영상)으로도
    동시 제작해 재사용하는 워크플로우 검토.

### 2-2. 배달의민족 '배달이'

- 확인 사례: 스톤브랜드컨설팅 아카이브, 뉴데일리, 헤럴드경제·한국경제(배민 웹툰 플랫폼 '만화경'
  관련 기사).
- **핵심 사실**:
  - '배달이'(본명 '독고 배달')는 2011년 앱 출시와 함께 탄생한 브랜드 마스코트이며, 배달이 콘텐츠를
    올리는 전용 인스타그램 계정 팔로워가 3만 4천 명 규모로 별도 채널을 운영.
  - 배민 운영사 우아한형제들은 2019년 8월 자체 웹툰 플랫폼 '만화경'을 론칭 — 기존 웹툰 플랫폼이
    다루지 않는, **SNS에서 대중 공감을 얻은 소재**에 집중하는 것이 차별점.
  - 마스코트 IP를 콘텐츠에서 그치지 않고 **선물하기 기능의 메시지 카드, 자영업자 대상 굿즈(비닐봉지,
    나무젓가락 등 배민상회 상품)**로 확장해 브랜드 접점을 늘림.
- **우리 시스템 적용 아이디어**:
  - 마스코트 인스타툰을 단순 SNS 홍보용으로 그치지 않고, 앱 내 알림 메시지·이벤트 배너·완료 화면
    등에도 같은 캐릭터를 재사용해 "SNS에서 본 캐릭터를 앱 안에서도 만난다"는 일관된 경험 설계를
    고려할 만함(별도 개발 필요 사항이므로 마케팅 콘텐츠 자체보다는 장기 아이디어로 기록).
  - 배달이처럼 마스코트 전용 계정을 따로 파기보다, 현재 우리 구조(앱 공식 계정 내 인스타툰 코너)를
    유지하되 "마스코트가 계정의 메인 화자"가 되는 캡션 톤(1인칭 시점, 앱이 아니라 캐릭터가 말하는
    방식)을 실험해볼 가치가 있음.

## 3. 터치/리플렉스 게임 앱 — ASMR·새티스파잉(satisfying) 게임플레이 클립 트렌드

- 확인 자료: Apptopia 블로그("ASMR themed mobile games 13분기 연속 증가"), Medium 아티클
  ("Relax, Swipe, Repeat"), Unity 하이퍼캐주얼 산업 리포트.
- **핵심 내용**:
  - ASMR/새티스파잉 장르는 하이퍼캐주얼 게임의 하위 트렌드로 **13분기 연속 앱 출시량이 증가**할
    만큼 꾸준히 성장 중 — 일시적 유행이 아니라 안정적인 콘텐츠 소재.
  - 마케팅 관점에서 성공하는 클립의 공통점: **한 번의 탭/스와이프로 이해되는 조작법 + 즉각적이고
    과장된 시각 효과(큰 이펙트) + 반복되는 "만족스러운 루프"**. 영상 길이는 6~30초로 짧고 정제된
    것이 릴스/카드뉴스 배치에 적합.
  - 슬라이싱, 믹싱, 텍스처를 조작하는 등 "반복적이지만 손맛이 느껴지는" 동작과 물리 시뮬레이션,
    화려한 색감이 감각적 만족감(ASMR 유사 경험)을 만들어냄.
  - 퍼즐/머지 게임에는 특히 ASMR 스타일 루프가 잘 맞는다는 언급 — 반응속도 게임에도 "정확히 맞았을
    때의 타격감 있는 이펙트+사운드"로 응용 가능.
- **우리 시스템 적용 아이디어(터치러쉬 직결)**:
  - 기존에 다룬 "반응속도 수치 자랑형 UGC"나 "이거 무슨 게임이야 리액션형" 콘텐츠와는 별개로, 터치
    성공 순간의 **이펙트·사운드·콤보 연출을 극대화한 6~15초 클립**을 별도 콘텐츠 유형으로 제작해
    릴스/카드뉴스 배경 영상 소재로 활용하는 안을 검토.
  - 카드뉴스 형태로 만들 경우, 정지된 스크린샷보다는 "터치 성공 순간의 이펙트가 터지는 프레임"을
    썸네일/커버로 우선 사용하면 감각적 만족감을 정지 이미지로도 어느 정도 전달 가능.
  - 캡션에는 화려한 스토리텔링보다 "이 소리 들으면 멈출 수가 없음" 류의 **감각 자극 자체를 소구**하는
    짧고 직관적인 문구가 이 장르와 궁합이 좋음(정보성/유머 톤과는 다른 제3의 톤으로 실험 가치 있음).
