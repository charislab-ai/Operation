## 1. 캐러셀 후킹(첫 슬라이드) 유형 분류 + CTA(마지막 슬라이드) 문구 패턴

### 후킹 유형 5가지 (첫 슬라이드 문구 공식)

검색 결과([imagine.art](https://www.imagine.art/blogs/best-carousel-hooks) 요약,
[contentdrips.com](https://contentdrips.com/blog/2026/06/carousel-hook-examples/) 요약 —
원문 직접 접근은 네트워크 정책상 차단되어 검색 스니펫 기준) 기준, 2026년 반복적으로 꼽히는
후킹 유형은 다음 5가지로 정리된다:

1. **궁금증 격차(Curiosity Gap)형**: 결론을 숨기고 중간 지점부터 보여준다.
   예: "나는 이렇게 해서 팔로워 40%를 잃었다. 뭘 바꿨는지 알려줄게" / "7번 슬라이드까지 보세요.
   못 믿을걸요."
2. **실수/손실(Mistake·Loss)형**: "대부분 이렇게 잘못하고 있다"는 위협감+공감을 동시에 준다.
   예: "이 카드뉴스 포맷 그만 쓰세요. 도달이 죽고 있어요." — "Stop"으로 시작하는 문장이
   스크롤을 멈추는 효과가 가장 크다고 분석.
3. **질문(Question)형**: 좁은 타겟 niche에 효과적. 예: "당신의 강아지가 스트레스받고 있다는
   신호 9가지, 대부분 놓칩니다."
4. **통계/충격(Statistic·Shock)형**: 놀라운 숫자로 시작. 예: "인스타그램이 2026년 당신 게시물의
   70%를 숨기고 있다."
5. **리스트/단계(List·Step)형**: "스와이프하면 전부 나옵니다" 구조. 예: "150만원으로 7일 이탈리아
   여행 짜는 법 →", "아이들이 진짜 먹는 5분 저녁 레시피 (전체 10개는 스와이프)".

공통 디자인 규칙: 첫 슬라이드는 "가장 센 버전의 후킹 문구"를 큰 글씨로 올리고, 우측 하단에
작은 화살표나 "Swipe →" 텍스트를 넣으면 스와이프율이 올라간다는 점이 반복 확인됨.

### CTA(마지막 슬라이드) 문구 목적별 분류

검색 결과([bestcontent.ai](https://bestcontent.ai/blog/article/instagram-carousel),
[adpicto.com](https://www.adpicto.com/en/blog/instagram-carousel-best-practices-2026),
[heytrendy.app](https://heytrendy.app/blog/how-to-make-an-instagram-carousel) 요약) 기준,
CTA는 목적에 따라 문구가 완전히 달라진다:

- **저장(Save) 유도**: "나중에 보려면 저장하세요" / "다음 작업 전에 저장하세요"
- **공유/DM 유도**: "필요한 친구에게 공유하세요" / "이거 필요한 사람에게 보내세요"
- **팔로우 유도**: "더 많은 [주제]를 보려면 @계정 팔로우"
- **댓글 유도(참여율↑)**: "제일 도움됐던 부분 댓글로 남겨주세요" / "[키워드] 댓글 남기면 DM으로
  풀버전 보내드려요" — 댓글+DM을 동시에 트리거하는 문구가 특히 효과적이라고 분석.
- **전환 유도**: "프로필 링크에서 지금 받아보세요"

핵심 포인트: **CTA를 하나만 쓰지 않고 두 개를 묶어서("Stack") 쓰는 게** 2026년 공통 추천
패턴이다. 예: "저장하고 더 보려면 팔로우하세요" — 저장(알고리즘 신호)과 팔로우(장기 구독)를
한 문장에 묶는 방식.

### 바로 적용할 수 있는 아이디어

- **전 앱 공통**: 카드뉴스 콘텐츠 캘린더에 "후킹 유형 로테이션" 규칙을 추가 — 같은 유형(예:
  통계/충격형)을 연속 2회 이상 쓰지 않고 5가지를 순환시켜 피로도를 줄인다.
- **전 앱 공통**: 마지막 슬라이드 CTA를 "저장+팔로우" 또는 "댓글+DM" 스택 문구로 통일 템플릿화.
  예: ChaMu — "이 벨소리 조합 저장하고, 더 보려면 팔로우하세요" / SNAPTAIL — "이 레이아웃
  저장해두고 다음 포토북에 써보세요" / Touch Rush — "점수 댓글로 자랑하면 챌린지 태그해드려요".
- **전 앱 공통**: ChaMu/SNAPTAIL처럼 "결과물을 보여주는" 콘텐츠는 "실수/손실형" 후킹이
  잘 맞는다. 예: "이 설정 하나 때문에 벨소리 소리가 깨지고 있을 수 있어요" (ChaMu),
  "사진 이렇게 고르면 포토북 망칩니다" (SNAPTAIL).

## 2. 벨소리/뮤직 앱 SNS 마케팅 — Zedge·Musixmatch 사례 + 바이럴 사운드→벨소리 전환 수요 (ChaMu 직결)

### 조사 내용

- **Zedge**(벨소리·배경화면 개인화 앱, MAU 3천만+)는 자사를 "폰 개인화(personalization)"
  플랫폼으로 포지셔닝하며, 핵심 콘텐츠 카테고리를 벨소리·배경화면·라이브 배경화면·알림음
  4가지로 명확히 나눠 소통한다. 2026년 기준 "배터리 잔량 기반 배경화면", "워치페이스" 등으로
  콘텐츠 카테고리를 계속 확장 중이며, 매출의 90% 이상이 광고 인벤토리에서 나오는 구조라
  무료 콘텐츠 다양성 자체가 핵심 성장 레버라는 점이 확인됨
  ([blog.zedge.net](https://blog.zedge.net/beyond-the-ringtone-how-zedge-is-redefining-mobile-personalization/),
  [appsamurai.com](https://appsamurai.com/blog/mobile-app-success-story-zedge/)).
- **Musixmatch**는 "가사 앱"에 머물지 않고 Instagram과 공식 파트너십을 맺어 **아티스트가
  자기 곡의 가사를 Instagram 스토리에 직접 넣을 수 있게 하는 기능**을 마케팅 포인트로 쓴다
  ([medium.com/musixmatch-blog](https://medium.com/musixmatch-blog/musixmatch-for-artists-how-to-add-your-song-lyrics-to-your-instagram-story-10b4b0cea9ee)).
  즉, "우리 앱의 결과물을 SNS 네이티브 포맷(스토리)으로 바로 내보낼 수 있다"는 것 자체가
  콘텐츠 마케팅 소재가 된다.
- 벨소리 메이커 앱 시장 리포트([cognitivemarketresearch.com](https://www.cognitivemarketresearch.com/ringtone-maker-apps-market-report))와
  일반 앱스토어 트렌드 검색 결과를 종합하면, 2026년 벨소리 앱 수요를 끌어올리는 핵심은
  "**틱톡/릴스에서 바이럴된 사운드·밈 오디오를 그대로 벨소리로 바꾸고 싶어하는 욕구**"다.
  Garage Ringtones 같은 앱은 "TikTok 콘텐츠에서 바로 벨소리 추출" 기능을 핵심 셀링포인트로
  내세운다.
- 릴스 특화 데이터: 릴스 시청자의 75%가 소리를 켠 채로 본다는 점, 그리고 유행 음원에 맞춰
  소재를 만들면 주목도가 크게 오른다는 점이 국내 블로그([kindagrowth.com](https://kindagrowth.com/column/?bmode=view&idx=166112222))에서도
  재확인됨 — 벨소리 앱처럼 "소리가 본질인 앱"일수록 무음 환경(카드뉴스)보다 **소리가 핵심인
  릴스 포맷**과의 결합이 더 유리하다는 시사점.

### 바로 적용할 수 있는 아이디어 (ChaMu)

- **"이번 주 틱톡/릴스 바이럴 사운드 → ChaMu 벨소리 변환" 시리즈 콘텐츠**를 정기 포맷으로
  만든다. "이 사운드 이번 주에 또 떴죠? ChaMu로 10초면 벨소리 됩니다" 식의 타임리 콘텐츠.
  Garage Ringtones의 "바이럴 오디오 그대로 추출" 포지셔닝을 참고.
- **"벨소리를 스토리로 바로 공유"하는 기능/콘텐츠**를 Musixmatch식으로 마케팅 소재화 —
  완성된 벨소리의 파형/가사 스니펫을 인스타 스토리용 세로 이미지로 바로 내보내는 "공유 카드"를
  제공하면, 사용자가 자발적으로 스토리에 올리는 바이럴 루프를 만들 수 있다.
  (레이아웃은 이미 등록된 "숫자 강조형"/"볼드 타이포형" 조합으로 충분히 구현 가능.)
- **Zedge처럼 콘텐츠 카테고리를 명확히 분리해 라벨링**: ChaMu 피드/릴스를 "오늘의 바이럴 벨소리",
  "커스텀 알림음 꿀팁", "아이폰 설정 꿀팁" 등 고정 카테고리로 나눠 하이라이트/캡션 태그로
  일관되게 운영하면 팔로워가 원하는 콘텐츠를 더 쉽게 찾는다.

## 3. 카드뉴스 시각적 레이아웃/틀 — 유사 앱 실제 사례 기준 재검증 (신규 spec 없음)

이번 회차는 범용 트렌드 블로그(whaaat.ai, My Social Boutique, panoslice 등 — 그동안 반복
재검증) 대신, ChaMu/SNAPTAIL과 직접 경쟁·인접한 실제 앱들(Zedge, Musixmatch, PastBook,
SCRL)의 실제 디자인 레퍼런스를 확인하려 시도했다.

- Zedge UI 상세 분석 페이지(screensdesign.com)와 캐러셀 후킹/CTA 상세 블로그 2곳
  (gethookd.ai, contentdrips.com, imagine.art)은 네트워크 egress 정책상 접근이 차단되어
  구체적 비주얼 레퍼런스(스크린샷, 색상 코드 등)를 직접 확인하지 못했고, 검색 스니펫 수준의
  정보만 확보했다.
- PastBook("폰·인스타·페북·드라이브 연결, 60초 포토북")은 09-30/10-02 회차에서 이미 다룸,
  SCRL("#1 seamless Instagram carousel 콜라주 앱")은 파노라믹 포맷과 동일 개념으로 10-02/10-03
  회차가 이미 다룬 "패노라믹(이어붙임)" 틀과 겹침, Mixbook Story Mode(AI 프롬프트 기반 포토북
  생성)는 *기능*이지 *카드뉴스 레이아웃*이 아니므로 레이아웃 spec과 무관함.
- 결론: 이번 회차 접근 경로로는 기존 등록 14종 틀(밈/임팩트형·오버레이 기본형·매거진 카드형·
  폴라로이드형·스크랩북형·인용구형·체크리스트형·앱화면 쇼케이스·숫자 강조형·볼드 타이포형·
  인생네컷 필름스트립형·후기 인증 카드형·글래스카드형·인스타툰 코믹패널형)과 겹치지 않는
  신규 레이아웃을 확인하지 못함 — **신규 layout-spec 제안 없음**.
- 참고로 확인된 구조적 한계: 현재 spec은 카드 1장당 `photo_area` 1개만 지정 가능해 "두 사진을
  한 화면에 좌우로 배치하는 진짜 스플릿스크린 비교"는 표현할 수 없다. 다만 Before/After류는
  슬라이드 2장(1장=Before 전면사진, 2장=After 전면사진)으로 캐러셀 자체에서 구현되므로, 이는
  spec 확장이 필요한 "진짜 신규 레이아웃"이 아니라 콘텐츠 기획(슬라이드 순서) 문제로 재확인함.
