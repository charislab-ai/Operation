## 1. 카드뉴스 시각적 레이아웃/틀 — "가짜 문자메시지/DM 스크린샷형" 스토리텔링 포맷 (신규 spec 없음)

기존 회차들(09-26~10-07)이 매거진/스크랩북/글래스카드/비전보드/메모장/네온 등 "정적인 디자인
스타일"을 다뤄왔다면, 이번엔 **대화(메시지/DM)를 그대로 캡처한 것처럼 꾸며 스토리를 전달하는
포맷** 자체를 처음 확인했습니다.

- **포맷 설명**: 각 슬라이드(또는 영상 프레임)를 실제 메신저 대화창처럼 꾸미고, 타이핑 인디케이터
  나 말풍선 타이밍을 흉내 내 "진짜 대화"처럼 보이게 만드는 캐러셀/릴스 포맷. 전용 생성 도구들
  (fake DM/chat generator)이 이미 다수 존재할 정도로 자리 잡은 포맷입니다.
  ([postnitro.ai](https://postnitro.ai/blog/post/animated-text-messages), [trymypost.com](https://www.trymypost.com/instagram/chat))
- **설득력의 핵심은 "타이밍"**: 디자인 완성도보다 메시지 간 등장 속도/간격이 더 중요하다는
  지적이 반복됨 — 유머·반전용은 빠른 템포, 감정적/설득형 소재는 느린 템포를 권장.
  ([postnitro.ai](https://postnitro.ai/blog/post/animated-text-messages))
- **디테일이 신뢰도를 좌우**: 말풍선 색(그라디언트 vs 단색), "읽음/전달됨" 표시 유무 등 플랫폼별
  실제 UI 디테일이 틀리면 "가짜"라는 인상을 주어 효과가 떨어진다는 경고가 다수 소스에서 공통
  언급됨(단, 정확한 색상값은 소스 간 불일치 — 실제 스크린샷 대조 필요).
  ([javii.tools](https://javii.tools/blog/fake-instagram-dm), [commoninja.com](https://www.commoninja.com/free-tools/social-media/fake-instagram-dm-generator))
- **스키마 적용성 검토**: 현재 spec 스키마(단일 photo_style + 단일 text_panel)로는 "여러 개의
  말풍선이 좌/우로 번갈아 쌓이는" 구조 자체를 표현할 수 없습니다. 메시지 1개만 보여주는 단일
  슬라이드라면 기존 "메모장 스크린샷형"(10-05-0903, text_panel: note + 사진 없음) 또는
  "인용구형(quote accent)" 조합으로 근사 표현이 가능하지만, 이 포맷의 핵심인 "대화의 흐름"은
  표현 불가 — 10-04-0903·10-07-0905 회차가 "신문형 컬럼"·"스티커 컷아웃형"에 대해 내린 결론과
  동일하게, 이는 스키마 확장(다중 말풍선 슬롯)이 필요한 영역이라 이번 포맷으로는 신규 제안을
  보류합니다.

**적용 아이디어**: 영상(릴스/숏폼) 포맷으로는 스키마 제약 없이 바로 활용 가능합니다. 예를 들어
"친구가 벨소리 추천해준 썰"(ChaMu), "엄마가 포토북 선물 받고 보낸 카톡"(SNAPTAIL), "게임 친구가
리더보드 보고 보낸 반응"(Touch Rush)처럼 실제 대화를 재연한 15~20초 영상을 만들어 공감/웃음
포인트로 활용. 카드뉴스(정적 캐러셀)로는 "말풍선 1개짜리 후킹 문구" 슬라이드 정도로 축소해
적용하고, 전체 대화 흐름이 필요한 소재는 영상 쪽으로 분리하는 것을 권장.

## 2. 페이스북 특화 포스팅 패턴 — "비공개 공유(Private Share)" 신호 강화 + 링크-댓글 전략 논쟁

기존 페이스북 전담 조사(09-15-0910·09-19-0903·09-27-0003·09-29-0002)가 9월 말 이후 끊겨 있었고,
10-02-0004·10-03-0003 회차에서 산발적으로만 언급됐습니다. 2026년 10월 기준 최신 가이드를
재확인했습니다(※ Meta 공식 발표는 확인되지 않아 업계 벤더 가이드로서 참고용임을 명시).

- **"비공개 공유"가 좋아요보다 중요해졌다는 업계 통설**: 메신저/왓츠앱으로 보내는 비공개 공유가
  현재 가장 강력한 오가닉 리치 신호라는 주장이 여러 벤더 가이드에서 반복됨(단, Meta 공식 확인은
  안 됨 — 벤더 주장으로만 취급). ([socialpilot.co](https://socialpilot.co/blog/facebook-algorithm), [omnichat.ai](https://blog.omnichat.ai/facebook-algorithm-increase-reach/))
- **체류 시간(watch time)이 정적 포스트에도 적용**: 릴스뿐 아니라 일반 피드 포스트도 "얼마나
  오래 머무르는지"가 신호로 작용한다는 설명.
- **"링크는 댓글에" 전략은 여전히 논쟁 중**: 일부는 "Meta가 캡션 내 링크를 권장하지 않는다"고
  보고하고, 다른 2026년 가이드는 "공식 확인된 바 없다"고 반박 — 확정된 사실이 아니라 커뮤니티
  보고 수준. 실무 조언으로는 "댓글에 LINK 남기면 보내드려요" 식으로 먼저 댓글 참여를 유도한
  뒤 실제 링크를 다는 방식이 있으나, 이는 Meta가 명시적으로 억제하는 "참여 유도(engagement
  bait)"로 분류될 위험이 있어 테스트 후 판단 필요.
  ([lilachbullock.com](https://www.lilachbullock.com/why-facebook-pages-post-links-in-comments/), [socialnewsdesk.com](https://www.socialnewsdesk.com/blog/meta-advises-including-links-in-post-comments))
- **포맷 믹스 권장**: 릴스=신규 발견(discovery), 피드=깊이 있는 콘텐츠(authority), 스토리·
  그룹=관계/신뢰 구축이라는 역할 분담 가이드.
- **빈도 경고**: 너무 자주 올리면 팔로워 이탈 위험이 있다는 경고와, 꾸준한 포스팅이 리치에
  유리하다는 조언이 동시에 존재 — "일관성 있으되 과하지 않게"가 공통된 결론.

**적용 아이디어**: ① 페이스북 캡션에 "이거 가족 단톡방에 공유해보세요" 식으로 비공개 공유(DM/
단톡방 전달)를 직접 유도하는 CTA를 넣어 테스트. ② 링크가 필요한 포스트(앱 다운로드 유도 등)는
우선 링크를 캡션에 직접 넣는 기존 방식을 유지하되, 소수 포스트에 한해 "댓글 링크" 방식을
A/B 테스트. ③ Instagram용으로 만든 캐러셀을 페이스북에 그대로 재게시하지 말고, 페이스북
전용으로는 "질문형 캡션 + 그룹 공유 유도" 버전을 별도로 작성.

## 3. Touch Rush 직결 — 하이퍼캐주얼 게임 리텐션 구조 + Duolingo 스트릭 공유카드 메커니즘

기존 Touch Rush 회차들(09-28-0004·09-30-0904·10-01-0004·10-03-0903·10-05-0903·10-06-0904·
10-07-0905)이 UA 광고 문법·챌린지 포맷·리더보드 초대·UGC 리액션·레이지베이트를 다뤘지만,
"스트릭(연속 플레이)"을 소셜에서 자랑하게 만드는 공유 메커니즘 자체는 처음 조사했습니다.

- **Duolingo의 인앱 스트릭 공유카드**: 사용자가 스트릭을 달성하면 앱을 벗어나지 않고 바로
  저장/게시할 수 있는 정사각형 공유 이미지(부엉이 캐릭터 + 불꽃 이미지 + "I just reached a
  streak!" 문구)가 자동 생성됨. 이 카드를 사용자가 직접 인스타그램에 올리는 것 자체가 바이럴
  루프가 됨. ([blog.duolingo.com](https://blog.duolingo.com/streak-milestone-design-animation))
- **브랜드 계정의 역할은 "증폭"**: Duolingo 공식 인스타그램은 바이럴을 직접 만드는 채널이 아니라
  일러스트/유저생성콘텐츠 리포스트/제품 소식 위주의 "브랜드 이미지 채널"로 작동한다는 분석 —
  실제 확산은 유저들이 자발적으로 올리는 스트릭 카드/댓글 상호작용에서 나온다는 점이 핵심.
  ([nogood.io](https://nogood.io/blog/duolingo-social-media-strategy/))
- **하이퍼캐주얼 업계의 리텐션 중심 전환**: 2026년 업계 분석은 하이퍼캐주얼 장르가 "볼륨
  중심"에서 "데이터 기반 리텐션·확장 가능한 참여 설계" 중심으로 이동했다고 설명 — 반복 세션을
  유도하는 게임 루프 설계가 핵심 지지축으로 언급됨(스트릭 메커니즘이 직접 언급되진 않았으나
  같은 맥락).
  ([medium.com](https://medium.com/@jackjill7659/hyper-casual-game-development-in-2026-scaling-engagement-speed-and-profitability-18413a5ae0d6))

**Touch Rush 적용 아이디어**: ① 일정 일수 연속 플레이(스트릭) 달성 시 Duolingo 방식처럼 앱을
벗어나지 않고 바로 인스타그램/카카오톡에 공유할 수 있는 "N일 연속 플레이 인증 카드"를 자동
생성하는 기능 검토 — 캐릭터/이펙트를 넣어 "자랑하고 싶게" 디자인. ② 이 공유카드를 리더보드
초대 기능(10-05-0903에서 다룬 친구 초대 리더보드)과 연결해 "스트릭 자랑 → 친구 초대 → 경쟁"
루프를 완성. ③ 공식 SNS 계정은 바이럴을 직접 만들려 하기보다, 유저가 올린 스트릭/리더보드 인증
게시물을 찾아 리포스트하는 "증폭자" 역할에 집중.
