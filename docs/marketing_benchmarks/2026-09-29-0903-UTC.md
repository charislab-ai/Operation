## 1. 카드뉴스 레이아웃 — 컷아웃/콜라주형 재점검 (신규 spec 없음)

2026년 가을 캐러셀 트렌드 아티클(mysocialboutique, whaaat.ai 관련 검색 결과 종합)에서 두 가지가
반복 언급됨:

- **컷아웃 스티커형(Cut-out)**: 사진에서 피사체만 오려내 알록달록한 단색 배경 위에 스티커처럼
  얹는 방식. 손글씨 텍스트·낙서 스티커를 더해 "포토덤프+스크랩북" 느낌을 냄.
- **2×2 콜라주 그리드**: 옷 코디, 제품 샷, 비포/애프터, 생일·여행 하이라이트 등에 쓰이는
  깔끔한 4분할 그리드. "발표 자료가 아니라 경험처럼 느껴지게" 하는 것이 2026년 전반적 방향.

**결론(신규 spec 미제안 근거)**: 컷아웃 스티커형은 09-27-0903 회차에서 이미 확인했듯
`background: brand_gradient` + `photo_style: circle`(또는 `card`) + `photo_area: center` 조합으로
기존 enum 내에서 재현 가능 — 재확인만 하고 넘어감. 2×2 콜라주 그리드는 "여러 장의 사진을 한 슬라이드에
동시에 배치"하는 멀티포토 그리드 구조라서, 현재 시스템의 `photo_style`/`photo_area` enum(단일 포토
영역 지정 방식)로는 표현이 안 됨 — 이건 스펙 파라미터 확장이 필요한 사안이라 이번 layout-spec
형식으로는 등록 불가. 시스템에 "한 슬라이드에 사진 N장을 그리드로 배치"하는 기능이 추후 추가된다면
꼭 검토할 가치가 있다는 점만 기록해 둠(이번 회차 spec 제안에는 포함하지 않음).

**바로 적용 가능한 아이디어**: 기존 폴라로이드형/스크랩북형 틀에 "여러 장을 겹쳐 티저처럼 살짝
보여주기"(맨 위 사진만 크게, 아래 사진들은 모서리만 살짝 보이게)는 `photo_tilt`를 슬라이드마다
다르게 준 폴라로이드 카드를 연속 배치하는 방식으로 지금도 구현 가능함.

## 2. 스냅스(SNAPS) — 인스타그램 연동 자동 포토북 + 추천 이벤트

- **브랜드**: 스냅스(SNAPS, (주)위블링 운영) — 국내 최대급 사진인화·포토북·굿즈 서비스.
  공식 인스타그램 [@snaps_com](https://www.instagram.com/snaps_com/)(팔로워 약 1.9만), 굿즈
  전용 계정 @snaps_goods 별도 운영.
- **핵심 기능형 마케팅 — "인스타그램북"**: 스냅스 앱에서 사용자의 인스타그램 계정을 연결하고
  원하는 기간을 선택하면, 해당 기간 게시물·사진·댓글을 그대로 불러와 자동으로 포토북 레이아웃을
  만들어줌. 실제 이용 후기로 "남자친구와의 데이트 사진으로 커플 인스타그램북을 만들어 선물",
  "요리 사진을 해시태그로 모아 나만의 요리책으로 출판해 딸에게 선물" 같은 구체적 사용 시나리오가
  확인됨. ([인스타그램 사진 그대로 포토북 관련 기사](https://www.intn.co.kr/news/articleView.html?idxno=565307))
- **AI 구독 기능**: 매달 AI가 사용자가 업로드한 사진 중 베스트컷을 자동으로 골라 포토북을 만들어
  배송해주는 구독 서비스를 최근 출시(리마인더·자동화로 "매달 습관적 구매"를 만드는 구조).
- **추천/리퍼럴**: 친구 추천 시 추천인에게 적립금(스냅스 "머니"), 피추천인에게도 혜택을 주는
  구조의 친구추천 이벤트를 상시 운영.

**바로 적용 가능한 아이디어(SNAPTAIL)**:
1. **"인스타그램/카카오톡 앨범 자동 불러오기 → 포토북 초안 자동 생성"** 기능을 마케팅 훅으로
   전면에 내세우기 — "이미 있는 사진 고르는 게 귀찮다"는 진입장벽을 제거하는 UX를 카드뉴스
   1~2슬라이드에서 "기간만 선택하면 끝" 식으로 보여주는 데모형 콘텐츠 제작.
2. **관계/테마별 포토북 시나리오 캡션**: "커플 1년 기록", "아이 돌잔치 전 12개월", "우리 가족
   여행 모음" 등 구체적 관계·상황을 특정해 저장/공유를 유도하는 캡션 패턴(스냅스 후기 사례를
   그대로 캡션 소재 템플릿으로 활용 가능).
3. **정기구독형 "매달 자동 포토북" 콘텐츠**: SNAPTAIL도 "이번 달 사진을 안 고르고 그냥 받아보는"
   구독/자동화 기능이 있다면, "귀찮음 제로"를 핵심 소구점으로 하는 짧은 후킹 카피(예: "이번 달
   사진 정리, 이미 끝났습니다") 시리즈로 활용.
4. **추천인 리워드형 이벤트**: 친구 추천 시 양쪽 모두 혜택을 주는 구조는 SNAPTAIL/SNAPTAIL 관련
   앱의 바이럴 루프 설계에 그대로 참고 가능.

## 3. 터치/리플렉스 게임 — TikTok "리액션 타임 테스트" 필터 챌린지

- **트렌드 개요**: TikTok에서 `#reactiontime`, `#f1reactiontest`, `#f1lightsoutreactiontest` 등
  해시태그로 확산 중인 반응속도 테스트 필터. F1 그리드 스타트처럼 5개의 빨간 불이 꺼지는 순간
  화면을 탭해 반응속도를 측정하는 방식이 특히 인기(관련 영상 다수가 좋아요 10만~20만, 댓글
  1만~4만 건대 기록).
- **참여 메커니즘**: 영상을 재생하다 "라이트 아웃(불이 꺼지는)" 또는 "초록불로 바뀌는" 순간
  화면을 정지/탭해 자신의 반응속도를 확인 → 댓글에 기록(ms) 공유 → "나도 해봄" 식으로 친구를
  태그하며 확산. "임파서블 리액션 테스트"류는 실패율 99%를 내세워 "혹시 나는 성공할까?" 하는
  호기심으로 클릭을 유도.
- **브랜드 활용 시사점**: 리액션/타이밍 기반 미니게임은 "명확한 제약(타이머·1회성 판정)"이 있을수록
  참여 장벽이 낮고, "댓글에 기록 공유"라는 텍스트 기반 인증이 영상·사진 인증보다 참여 허들이 낮아
  확산 속도가 빠르다는 점이 확인됨(같은 카테고리 앱 "Say The Word On Beat Challenge"도 동일한
  "반응속도+리듬+타이밍" 구조로 챌린지형 바이럴을 설계).

**바로 적용 가능한 아이디어(Touch Rush)**:
1. **"F1 스타트 라이트" 테마 모드/필터 콘텐츠**: 터치러쉬 게임플레이 중 F1 그리드 스타트를
   패러디한 짧은 릴스(불 5개가 꺼지는 순간 탭 → 기록 표시)를 만들어 기존 TikTok 트렌드 포맷에
   그대로 편승. 기존 09-21 회차의 "스코어카드 공유" 메커니즘과 결합해 "내 반응속도 vs F1 드라이버
   평균(약 200~250ms)" 비교 스코어카드를 자동 생성하면 두 트렌드를 한 번에 활용 가능.
2. **"99% 실패" 훅 카피**: "임파서블 리액션 테스트"처럼 실패율을 앞세운 후킹 문구
   ("이거 통과하는 사람 100명 중 1명도 안 됩니다")를 릴스 도입부·카드뉴스 첫 슬라이드 카피로 재사용.
3. **댓글 기록 인증 유도**: 영상/스토리 CTA에서 "당신의 반응속도(ms)를 댓글에 남겨보세요" 식으로
   텍스트 기반의 낮은 허들 인증을 유도해 댓글 참여율 자체를 늘리는 코멘트 유도형 CTA 설계.
