## 1. 뮤직/벨소리 앱의 SNS 마케팅 스타일 — Zedge 사례 중심

- **Zedge**(벨소리·알림음·배경화면 앱, 다운로드 5억+): 유료 광고보다 유저들이 자발적으로 올리는
  틱톡/인스타 콘텐츠가 마케팅의 중심 축. 확인된 콘텐츠 유형은 크게 4가지.
  1. **밈/개그 스킷형**: "Mental Health Hotline Ringtone" 같은 특정 벨소리를 소재로 한 짧은
     코미디 스케치. 앱 자체를 설명하지 않고 벨소리를 웃긴 상황극의 소품으로만 씀.
  2. **세대 반전(unexpected user)형**: 할머니가 크리스마스 벨소리를 Zedge로 바꾸는 영상처럼,
     "이 앱을 쓸 것 같지 않은 사람"이 쓰는 모습을 보여줘 "누구나 쉽게 쓸 수 있다"는 메시지를
     귀엽게 전달.
  3. **튜토리얼형**: "삼성/아이폰에서 커스텀 벨소리 설정하는 법" 같은 실용 정보 콘텐츠로 앱을
     자연스럽게 노출.
  4. **트렌드 오디오 활용형**: 틱톡 인기 오디오/챌린지에 자사 벨소리 라이브러리를 태그해 발견성을
     높임.
- **일반 뮤직 앱/아티스트 계정 트렌드**(2026년 기준, 여러 소스 공통):
  - 릴스 주 3~5회 + 스토리 데일리 업로드 유지 시, 불규칙 업로드 대비 프로필→스트리밍 전환율이
    40~60% 높다는 관측치가 반복 언급됨.
  - 2026년 알고리즘은 "좋아요 수"보다 **완청률(watch-through rate)**과 **오디오 재사용 횟수**를
    더 높게 평가함 → 짧고 훅이 강한 클립이 유리.
  - 팔로워 수보다 "니치 마이크로 인플루언서와의 진정성 있는 협업"이 전환에 더 효과적이라는 견해가
    다수.
  - 벨소리 카테고리 한정으로는 "클립처럼 다루지 말고 제품처럼 홍보하라(훅에 집중, 짧게)"는 조언과,
    12~1월(연말연시) 검색 수요가 급증한다는 계절성이 확인됨.
- **바로 적용할 아이디어(ChaMu)**:
  - 카드뉴스/정보성 콘텐츠 위주 구성에 더해, "밈/개그 스킷형" 숏폼 1개를 실험적으로 넣어보기 —
    예: ChaMu로 만든 알림음을 소재로 한 짧은 상황극(알림음 때문에 웃긴 일이 생기는 콘셉트).
  - "세대 반전형" 콘셉트 차용: 벨소리 커스터마이징에 익숙하지 않을 법한 캐릭터(예: 부모님, 나이든
    사용자 페르소나)가 ChaMu로 쉽게 알림음을 만드는 모습을 보여주는 짧은 시나리오.
  - 마케팅 콘텐츠 생성 로직에 "아이폰 전용 벨소리/알림음 설정법" 같은 실용 튜토리얼 카드뉴스를

## 2. 캐주얼/하이퍼캐주얼 게임 앱의 SNS 마케팅 스타일 — Voodoo·Homa Games 사례

- **Voodoo — "게임 커멘터리(Game Commentary)" 크리에이티브**: 게임 플레이 화면 위에 사람이
  실시간으로 감정을 넣어 코멘트하는 음성/텍스트를 얹는 포맷. "Deliver It 3D" 사례에서 이 포맷이
  일반 플레이 영상 대비 **CTR 49% 상승, CPI 52% 하락**을 기록. 핵심은 순수 게임 화면보다 "사람의
  리액션"이 붙었을 때 정서적 몰입과 맥락 이해가 커진다는 점.
- **Homa Games — 대량 크리에이티브 + 트렌드 재해석**:
  - "Attack Hole" 캠페인에서 **500개 이상의 서로 다른 크리에이티브**를 제작해 크리에이티브
    피로도(같은 광고를 반복 노출해 성과가 떨어지는 현상)를 방지하고 다양한 시장에 맞춰 확장.
  - "Clean It" 캠페인은 당시 유행하던 "#CleanTok"(청소 브이로그) 트렌드를 게임 컨셉과 결합해
    틱톡 크리에이티브 챌린지(TTCC)로 제작 → 일반 인하우스 크리에이티브 대비 **플레이타임
    +10%, CTR 2.85배**.
- **공통된 2026년 하이퍼캐주얼 UGC 원칙**:
  - 폰카메라로 찍은 듯한 러프한 컷, 손이 보이는 화면, 즉흥적인 자막이 "광고 같지 않은 광고"로
    인식돼 피드에 자연스럽게 섞이고 광고 피로도를 회피함(고퀄리티 시네마틱 트레일러보다 효과적).
  - UGC를 유발하는 핵심 감정 트리거는 "도전(challenge)", "답답함(frustration)",
    "카타르시스(satisfaction)" 세 가지 중 하나에 명확히 대응해야 함.
  - 전환이 잘 되는 포맷은 **"실패 상황(fail-state)"**을 보여주는 클립과 **"이렇게 하는 거야"류
    튜토리얼 클립** — 완벽한 플레이보다 "아깝게 실패하는 순간"이 재도전 욕구를 자극함.
  - 메가 인플루언서 1명보다 수백 명의 마이크로 인플루언서를 동시에 활성화하는 방식이 2026년
    트렌드로 언급됨.
- **바로 적용할 아이디어(Touch Rush)**:
  - 게임 소개 영상에 실제 사람이 리액션하듯 반응하는 자막/보이스오버("어어어 이거 완전 아깝다!"
    류)를 얹은 버전을 별도로 제작해 순수 플레이 화면 버전과 A/B 비교.
  - "아쉽게 실패하는 순간"(예: 0.1초 차이로 콤보가 끊기는 장면)을 하이라이트로 편집한 숏폼을
    정기 포맷으로 추가 — 지금처럼 "성공/고득점" 장면 위주가 아니라 실패 순간도 후킹 소재로 활용.
  - 카드뉴스 대비 "폰카메라로 찍은 듯한 러프한 스타일"의 저퀄리티 지향 숏폼 클립을 별도 트랙으로
    같이 운영해, 지나치게 정제된 톤 하나로만 발행되지 않도록 다양성 확보.
  - 콘텐츠 생성기에 "실패 클립 강조형", "리액션 커멘터리형" 같은 새 포맷 프리셋을 추가하는 것을
    검토.
